# Implementation Plan

> 前提: 本 spec の作業は worktree `spec/store-suspension-252` で行う。着手時と PR 提出の直前に `origin/main` を取り込み、migration の番号（`0012`）・`ck_audit_logs_action` の値集合・述語の置き場所が他の PR に動かされていないかを確かめる。
> 規律: ガードと検査は「先に入れて赤を実測してから直す」。変異を回す前にコミットし、復元は差分の打ち消しで行う（`git checkout --` で未コミットの実装ごと消さない）。

  - Requirement 3.10 を、オーナー自身の停止手段を提供しないことと、運営・代理店の停止は store-suspension が定めることを区別する文へ改め、改訂日と Issue #252 を注記する
  - 改訂後の competitive-daily-summary の要件文書に、オーナー自身の停止と運営・代理店の停止が別の能力として書き分けられている

- [x] 1.2 確定の判定と停止の判定の件数照合ガードを入れ、現行ツリーで赤になることを確かめる
  - 本番コード（テスト・生成物・コメント行を除く）をファイルごとに走査し、印の無い確定の判定の数に対して停止の判定の数が足りないファイルを赤にする
  - 表示だけの判定の除外印は、理由必須・総数 1・置き場所は店舗一覧の画面ファイルだけ、をガード本体に宣言し、食い違いを赤にする。確定の判定が総数 0 のときも赤にする
  - 自己テストのケースを追加し、停止の判定を 1 つ消す・理由の無い印・宣言外の印・宣言数と食い違う印・コメント行だけの判定・判定 0 件の各変異で赤、正しい印つきで緑になることを確かめる

  - _Requirements: 4.5_

- [x] 1.3 店舗の停止時刻の列と、停止・再開の監査種別を追加する migration を作る
  - 店舗に停止時刻（任意・既定なし）を足し、監査種別の制約を既存 16 値に停止・再開を加えた 18 値で作り直す（制約の削除に存在確認を付けない）
  - TS の監査種別の一覧に停止・再開を足し、既存の集合一致テストを 18 値で緑にする
  - ERD と書込境界の文書に、停止時刻の意味と書込元（運営・代理店の停止操作）を追記し、文書と実スキーマの整合検査を緑にする

- [ ] 1.4 停止時刻の列単位の書込権限を検証する DB 検査を入れ、権限を列単位へ改める
  - テスト DB に本番と衝突しない名前で 6 つのランタイムロールを作り、権限定義ファイルを実際に適用して列単位の権限を問う検査を作る。終了時にロールを片付け、ロール作成の権限が無ければ赤にする
  - 検査は、ダッシュボードだけが停止時刻を更新でき、LINE 応答と客向け Web は停止時刻を追加・更新できず、それ以外の店舗の全列は従来どおり追加・更新でき、バッチ・配信・詳細閲覧は停止時刻を更新できないことを問う。走査した列が 0 なら赤
  - 検査を DB 検査の実行装置の RUN 表へ登録し、CI 配線の宣言ガードを緑にする
  - 権限を改める前の定義で検査を流すと、LINE 応答と客向け Web が停止時刻を書けるため赤になることを先に確かめる
  - 権限定義で、LINE 応答と客向け Web の店舗への追加・更新をテーブル単位で剥がし、停止時刻を除く列を列挙して与え直すと、検査が緑になる
  - _Requirements: 8.1, 8.3, 8.4_
  - _Depends: 1.3_

- [ ] 2. データ層: 停止状態の読み書き
- [ ] 2.1 範囲つきで停止状態を切り替える操作と、店舗の読み出しでの停止時刻の返却を実装する
  - 店舗の範囲（運営は全店、代理店は自代理店）と状態の更新を 1 回の操作で行い、変化あり・変化なし・見つからない（不存在と範囲外を区別しない）の 3 通りを返す
  - アンケート用・QR 用・一覧用の店舗の読み出しが停止時刻を返す
  - 実 DB の試験で、停止時刻以外の列と匿名集計が変わらないこと、同じ店舗へ同時に 2 回停止すると変化ありが 1 回だけであること、他の代理店の店舗が見つからない扱いで行が変わらないことが緑になる
  - _Requirements: 1.1, 1.2, 1.3, 1.4, 1.5, 1.7, 5.3_

  - 試験で、停止中の店舗が両方の抽出に出ず再開後は出ること、再開後の最初の集計が前日の集計を持たないため前日比を持たず新着を 0 とすることが緑になる。各条件を 1 つずつ消す変異で赤になることを実測する

  - _Depends: 1.3_

- [ ] 3.2 (P) 日次の変化通知の対象と見送り記録の対象から停止中の店舗を外す
