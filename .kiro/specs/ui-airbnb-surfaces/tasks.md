## 実施記録

### 1.1 面の側に置く色の実効値（2026-09-03）

追加したのは 3 組（いずれも α=1・面はページ背景）。ワードマーク 2 箇所は同一の組なので 1 行にまとめた。

| 前景 | 対ページ背景 | 判定 | 面の側の用途 |
|---|---|---|---|
| `brand` | 3.516 | 既知の限界 | 帯とログイン画面のワードマーク（大きい文字としてのみ） |
| `text` | 15.910 | AA | 店舗詳細の順位の巨大表示・客向けアンケートの選択済みの星 |
| `textMuted` | 5.409 | AA | 客向けアンケートの未選択の星 |

**値は自分で計算していない。** 意図的に誤った値を書いて得た失敗メッセージの実測値を採った。
RED は 3 段階に分かれる（面の実効色 → 前景の実効色 → 比。assert が先頭で打ち切るため）。

独立レビューは本体を無改変のまま symlink ミラー上で 5 通りの変異を流し、新規 3 行が個別に赤化すること・
死んだ語彙の検査が両方向で生きていること・判定語彙の選択をテストが決めないことを実証して APPROVED を返した。

観察可能な完了条件の確認:

```
pnpm -C ts --filter @fwlm/ui exec vitest run test/design-language-doc.test.ts
```

144 件緑。この検査は表の行ごとにテストを生成し、`compositeOver` と `contrastRatio` で実効色と比を
再計算して照合するため、行を足せば母数が増え、値を 1 つ書き換えれば赤くなる。

### 1.2 訂正 2 件と追記 2 件（2026-09-03）

訂正は design.md が範囲に含めた 2 件ちょうどである。

- **7.1 未選択の星**: 罫線色から補足色へ。罫線色は純装飾として定義された値で対白 1.358 しかなく、
  現行実装の 5.409 から退行する。1.1 が 2.2 節へ入れた行と整合する
- **7.3 巨大表示の寸法**: 64px から §6 の最大段（`text-2xl`・`1.5rem`）へ。意図が求める大きさに足る段が
  スケールに無く、段の追加はトークン層の変更で境界を超えるため暫定とした。最大段は主見出しと同寸なので
  一意性の主張は暫定の間は外し、復活の条件と追跡先
  [#185](https://github.com/ManatoYamashita/fw-line-meo/issues/185) を書いた

追記は 7.8（帯の高さと現在地の示し方）と 7.9（ログイン画面の版面）。併せて 2.1 の装飾専用色の用途欄を
「通常の文字にも」へ限定した（同じセル内で大テキストを許す記述と文字全般を禁じる記述が同居して読みが割れていた）。

**独立レビューは 1 巡目で REJECTED を返した。** 帯の高さを原典の 80px から 64px へ下げており、
根拠の「散文の rem ガードが赤くなる」が偽（ガードは散文中の rem リテラルだけを見るので `h-20` と書けば発火しない）、
補強の「原典の帯は検索バーを収めている」が原典の誤読（`top-nav` は 80px・`search-bar-pill` は別部品で 64px）、
かつ design.md が訂正を 2 件に限っているため境界違反だった。差し戻して 80px へ戻し、2 巡目で APPROVED。
